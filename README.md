# IT support work samples

Practical examples of the short handover documents I can provide for a scoped support task. **Every person, device, and organization in this repository is fictional.** These are self-directed templates, not paid client engagements or screenshots of an employer environment.

I work in IT support and systems administration in Dubai. My hands-on background includes Windows endpoint support, Active Directory and Group Policy tasks, VPN support, backup work with Duplicati and Veeam, and monitoring with Uptime Kuma and Zabbix. I have also worked on HPE Gen10 and MSA-backed cluster builds. The examples here focus on small jobs that can be scoped, checked, and documented.

## How I use a sample

1. Confirm the system owner, access method, one-user/device scope, time window and expected result.
2. Record the current state and check data protection before making a change.
3. Do only agreed actions; test with the client or delegated system owner.
4. Hand over a short record of observations, actions, outcome and remaining work.

These files are templates, not a promise to take responsibility for a production environment, monitor it continuously, or guarantee recovery. Replace fictional values with the client's approved information inside the client's own workspace. Never put client credentials, mailbox contents, personal data, or real infrastructure diagrams in a public repository.
