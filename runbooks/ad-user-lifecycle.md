# Active Directory user lifecycle checklist

**Status:** fictional template for an authorized administrator. It records checks; it is not an executable script or evidence of a completed client job.

## New user

1. Confirm an approved request, manager, start date, naming convention and identity details with the system owner.
2. Create or update the account using delegated privileges and the organization's naming and password policies.
3. Add only approved groups and access. Record who approved each change.
4. Verify sign-in, initial password change or approved MFA enrollment, and the expected Group Policy application with the user or owner.
5. Record account ID, ticket ID, groups assigned, test result and any follow-up without storing a password.

## Leaving user

1. Confirm the authorized offboarding request and effective time.
2. Disable sign-in or follow the organization's defined offboarding sequence; handle sessions and access according to its policy.
3. Record group changes, device return, shared resources, data retention and mailbox handover as separately approved tasks.
4. Verify the requested access state and give the owner a change record and any unresolved items.

| Change record | Value |
| --- | --- |
| Request/ticket ID | Pending |
| Approver and scope | Pending |
| Account and affected groups | Pending |
| Actions and time | Pending |
| Validation and owner signoff | Pending |

Do not copy employer or customer account lists to a personal portfolio. Group Policy design, privileged access and tenant-wide changes require their own scope and review.
